StockDesk Inventory
===================

Inventory management for the WordPress admin: products, suppliers,
stock movements and low-stock tracking.

Requirements
------------
- WordPress 6.0 or later
- PHP 7.4 or later

Installation
------------
1. Copy the stockdesk-inventory folder into wp-content/plugins/.
2. Activate StockDesk Inventory from the Plugins screen.
3. Open Inventory in the admin menu.

Features
--------
- Overview with stock counts and recent activity
- Products and suppliers
- Stock in, stock out and set-stock adjustments
- Stock history
- Low-stock list
